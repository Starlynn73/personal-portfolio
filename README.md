# Personal Portfolio

Individual IS117 portfolio skeleton. Separate from the T-shirt and group project repositories.

## Pages
- `index.html`: home
- `about.html`: background
- `projects.html`: future project placeholders
- `research.html`: internships, full-time career references, and required skills
- `documentation.html`: public research, planning, and review record

Built with HTML and CSS. No installation or build required. For GitHub Pages, select **Deploy from a branch → main → / (root)**.

Project content will be added later. Full career reflections and personal eligibility circumstances stay private in Canvas.
